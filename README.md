# Шаблон «Минимализм» — свадьба

## Файлы
| Файл | Что внутри | Менять под клиента? |
|---|---|---|
| `config.json` | все данные пары и цвета | **да, только его** |
| `images/` | фото (cover, place, photo-1…) | да, заменить файлы |
| `index.html` | разметка блоков | нет (только при правке дизайна) |
| `style.css` | внешний вид | нет (только при правке дизайна) |
| `script.js` | читает config.json и заполняет страницу | нет |

## Запуск на компьютере
Двойной клик по index.html не сработает (браузер не даёт читать config.json с диска). Нужно:
```
cd wedding-minimal
python -m http.server
```
Открыть http://localhost:8000

## Как собрать заказ
1. Скопировать папку целиком, назвать по паре.
2. Заменить фото в `images/` (обложка вертикальная, ~1080×1920, до 500 КБ).
3. Отредактировать `config.json`.
4. В `index.html` поправить 3 строки `og:` (текст превью ссылки в мессенджере).

## Правила config.json
- Удалил раздел (например `"gallery"`) или сделал его пустым `[]` → блок исчезает со страницы.
- `event.date` — формат `ГГГГ-ММ-ДДTЧЧ:ММ:00+03:00` (+03:00 — Москва, для Калининграда +02:00).
- `dateText` и `weekday` — пишутся словами вручную.
- `theme` — 5 цветов в HEX, вся палитра сайта меняется отсюда.
- `couple.coverPhoto: ""` → обложка без фото, на светлом фоне.
- `rsvp.endpoint: ""` → анкета в демо-режиме (подключим Google Таблицу на шаге 3).
- Валидность JSON проверять на jsonlint.com: частая ошибка — лишняя запятая после последнего элемента.
